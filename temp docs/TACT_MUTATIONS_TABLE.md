# Tact Mutation Table

Current for `universalmutator/static/tact.rules` and `universalmutator/comby/tact.rules`.
The default Tact flow uses `ton_common.rules` + `tact.rules`; shared boolean/comparison/assignment/while/break rules are documented separately in `TON_COMMON_MUTATIONS_TABLE.md`.

## Summary

| File                | Rule Count | Notes                                      |
| ------------------- | ---------: | ------------------------------------------ |
| `static/tact.rules` |        177 | Tact-specific regex layer                  |
| `comby/tact.rules`  |        154 | Comby equivalent for syntax-aware surface mutations |
| `ton_common.rules`  |         36 | shared layer loaded before `tact.rules`    |
