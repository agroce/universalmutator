# Tolk Mutation Table

Current for `universalmutator/static/tolk.rules` and `universalmutator/comby/tolk.rules`.
The default Tolk flow uses `ton_common.rules` + `tolk.rules`; shared boolean/comparison/assignment/while/break rules are documented separately in `TON_COMMON_MUTATIONS_TABLE.md`.

## Summary

| File                | Rule Count | Notes                                                                 |
| ------------------- | ---------: | --------------------------------------------------------------------- |
| `static/tolk.rules` |        156 | Tolk-specific regex layer                                             |
| `comby/tolk.rules`  |        234 | Comby equivalent for syntax-aware surface mutations; dict families are expanded explicitly |
| `ton_common.rules`  |         36 | shared layer loaded before `tolk.rules`                               |
